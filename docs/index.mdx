# Follow the evidence

Tracexy is a native macOS network intelligence app. Start with a process, host, or session; follow observations and findings to the exact packet bytes that support them. Live capture and saved PCAP/PCAPNG analysis stay local to your Mac by default.

**Capture → Session → Finding → Cited frame.** Each step keeps a path back to the observed evidence.
