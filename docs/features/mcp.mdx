**Status: Available**

Give a local client a scoped view of one Project’s History.

## Try it

In MCP settings, grant access to the intended Project, then explicitly copy the client configuration for this Mac. Connect the client and use the available description, capture, session, and finding projections. Revoke the grant when done.

## What you can see

The bundled stdio server has no network listener, capture control, or raw-packet tool. Grants expire and are revalidated; returned History pages are bounded and use minimum-disclosure fields.

## Coverage limits

The copied command is an absolute executable path specific to your Mac and may contain your account name. Keep it in local client settings. MCP reads History summaries, not open live packets or capture bytes.
