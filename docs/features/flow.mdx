**Status: Available**

See where observed sessions connect, then drill into an endpoint or path.

## Try it

Open **Flow Map** in the sidebar for the current scope. Select a destination or group to narrow Sessions, or return to the previous scope.

## What you can see

The view groups destination addresses by typed IP identity and reports omitted destinations. Region totals derive from the same bounded groups. Saved captures are treated as observed traffic, without assuming the source machine is your Mac.

## Coverage limits

A geographic label requires local enrichment data when configured and is never a claim about physical packet origin. Visual groups remain bounded for large captures.
