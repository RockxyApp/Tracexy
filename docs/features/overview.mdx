Start with the shape of the traffic, then move into the sessions behind it.

## Try it

Open **Overview** after a capture loads. Select a host, protocol, app, or finding to narrow the visible sessions; continue in **Sessions** or **Flow Map**. Use **Back to Previous Scope** to retrace a drill-down.

## What you can see

Counts and categories reflect observed and decoded evidence. Overview can carry an aggregate scope into Sessions and Flow Map while existing query and Noise Control choices remain active.

## Coverage limits

An absent host or protocol label does not prove its traffic was absent: capture loss, truncation, undecoded framing, and bounded observation can limit coverage.
