**Status: Partial**

Turn packet evidence into bounded traffic summaries.

## Try it

Open the **Statistics** menu for **Protocol Hierarchy**, **Packet Lengths**, **I/O Graph**, **Flow Graph**, **HTTP**, **IP Statistics**, **Service Response Time**, **Value Distribution…**, or **Plot…**. Narrow to sessions in view where offered, then copy or export the visible result.

## What you can see

Available views include protocol and length summaries, capture traffic over time, selected protocol statistics, value distributions, and numeric field plots. Bounded visualizations report omissions or downsampling.

## Coverage limits

A statistic is only as complete as the capture and the supported decoder. Some graphs count all timed frames; others count only scoped sessions. See each view’s scope control before comparing numbers.
