**Status: Partial**

Explore one selected session through a visible, bounded evidence brief.

## Try it

Select a session, open the **AI Assistant** tab in the right inspector, and review the exact brief shown before sending. Connect and choose a local model in **Settings → MCP**. Recheck the source and session scope before using a response.

## What you can see

The app prepares a local-only brief from retained session evidence. It rejects stale output when the selection or capture scope changes. The assistant does not silently attach raw capture files.

## Coverage limits

Model output is an interpretation, not packet evidence. There is no remote provider in the current public workflow; availability depends on a compatible local runtime.
