**Status: Available**

Keep investigations, preferences, libraries, and History separated by Project.

## Try it

Use the toolbar Project selector or **Project → Manage Projects…** to create, switch, rename, import, or export Projects. Choose a Project before opening or capturing traffic.

## What you can see

Each Project owns its sessions, workspaces, saved captures, History, capture settings, privacy settings, Focus Sets, and local names. A `.tracexyproject` export carries configuration only.

## Coverage limits

Project configuration may include user-authored filter text; review before sharing. It excludes packets, paths, History, findings, and selection. Switching during live capture first requires an orderly stop.
