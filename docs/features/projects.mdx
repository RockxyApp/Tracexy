**Status: Available**

Keep investigations, preferences, libraries, and History separated by Project.

## Try it

Use the toolbar Project selector or the **Project** menu — **New Project…** (⇧⌘N), **Rename Project…**, **Manage Projects…**, **Export Project Configuration…**, **Import Project Configuration…** — to create, switch, rename, import, or export Projects. Choose a Project before opening or capturing traffic. If the Project list itself fails to load, **Repair Projects…** appears in the same menu.

## What you can see

Each Project owns its sessions, workspaces, saved captures, History, capture settings, privacy settings, Focus Sets, local names, saved capture filters, saved Session Expressions and macros, saved frame filters, and frame coloring rules. A `.tracexyproject` export carries configuration only.

## Coverage limits

Project configuration may include user-authored filter text; review before sharing. It excludes packets, paths, History, findings, and selection. Switching during live capture first requires an orderly stop.
