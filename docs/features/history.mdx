**Status: Available**

Return to completed investigations without storing a second copy of raw packets in History.

## Try it

Open **History**, select a completed capture, and page through bounded capture and session summaries. Refresh when needed; use the confirmed clear action, or set **Auto-clear** in **Settings → Privacy**.

## What you can see

History stores bounded summaries and evidence-linked finding metadata. Capture time provenance distinguishes a captured time from an opened time, and missing timing stays unknown. Each Project has a separate local History database.

## Coverage limits

History is not a raw packet archive. To inspect exact packet bytes later, retain the original capture or saved file. **Auto-clear** removes only local History summaries, and only at launch, after a capture is added, and when the setting itself changes. Current capture data and saved files stay untouched.
