title: Command line

**Status: Partial**

Tracexy has a read-only command-line mode in its app executable. Run the executable inside your installed `Tracexy.app/Contents/MacOS` directory, or use a local shell alias named `tracexy` that points to it. The executable path is specific to your Mac; avoid putting it in shared examples or logs.

## Try it

```sh
tracexy summary capture.pcapng --json
tracexy sessions capture.pcapng --format json
tracexy findings capture.pcapng --fail-on warning
tracexy stats capture.pcapng --tap phs --format text
tracexy frames capture.pcapng --details
tracexy info capture.pcapng
```

`--expression` on supported commands uses a [Session Expression](/features/session-expressions), for example `finding == retransmission and port == 443`. Run `tracexy help` for the current list of statistics taps and options.

## Commands and output

| Command | Supported action |
| --- | --- |
| `summary`, `info` | Capture summary or file metadata. |
| `sessions`, `findings`, `frames` | Session, finding, and decoded-frame output. `frames` also accepts `--column Protocol:Field`. |
| `stats` | One or more supported `--tap` statistics. |
| `objects` | List supported HTTP, IMF, SMB, TFTP, FTP-data, or X.509 objects; `--body` emits one object's bytes. |
| `follow` | Reconstruct one matching TCP session; choose `ascii`, `hex`, `raw`, `c`, or `yaml`. |
| `select`, `merge` | Emit PCAPNG bytes to standard output. Redirect explicitly if you want a file. |
| `glossary` | List supported analysis terms. |

The process reads a local PCAP/PCAPNG capture, including supported gzip or LZ4 wrappers. It prints to standard output and does not open a capture interface, Project, Library, History store, or network listener. Shell redirection can create a file; `select`, `merge`, `objects --body`, and `follow --format raw` can emit sensitive packet bytes.

Exit codes are `0` for success, `1` for an unreadable capture, `2` for usage or expression errors, and `3` when `findings --fail-on` matches.
