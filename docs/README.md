# Tracexy documentation

The public Mintlify site is authored in this directory. Start with [`index.mdx`](index.mdx), [`quickstart.mdx`](quickstart.mdx), and the [feature coverage index](reference/feature-coverage.mdx), which lists every feature with its status and points to the coverage areas. Dedicated [`features/`](features/) pages describe current actions and limits. The [`coverage/`](coverage/) pages hold the detailed Wireshark workflow comparison, one capability per section, and label unavailable work **Coming soon** without a release date. [`docs.json`](docs.json) defines the navigation. [Deployment instructions](DEPLOYMENT.md) distinguish repository state from a live Mintlify site.

The longer source reference remains available here: [usage](usage.md), [protocol support](protocol-support.md), [capture migration](capture-migration.md), [privacy and security](privacy-and-security.md), [architecture](architecture.md), [the comparison ledger](comparison.md), and [getting started for contributors](getting-started.md). These references can be more detailed than the public guide; source and tests remain authoritative when they disagree.

Feature language uses **Available**, **Partial**, and **Coming soon**. Coming soon records a gap, not a release commitment. Review the catalog against the current source before changing public claims.
