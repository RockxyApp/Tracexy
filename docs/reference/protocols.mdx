# Protocol coverage

Tracexy decodes Ethernet and VLAN, Linux cooked, loopback and raw IP framing; ARP, IPv4/IPv6, ICMP, TCP/UDP; and selected application protocols. IPv4/IPv6 fragment reassembly is bounded. Supported application observations include DNS, mDNS, LLMNR, NBNS, DHCP, NTP, TFTP, TLS metadata, QUIC long headers, HTTP/1, HTTP/2, WebSocket, SIP, STUN, SSH, FTP, SMTP, POP3, IMAP, SSDP, SMB 2/3, Kerberos and LDAP. GRE and VXLAN tunnels are unwrapped to the inner conversation, at most two deep. **Help → Supported Protocols** lists every protocol the installed build recognizes, what is read from each, and the Session Expression keywords that find it. Some richer application views are available only through explicit Follow or Statistics actions.

This is a **bounded, selected protocol set**, not Wireshark's dissector catalog. TLS and QUIC payload decryption, arbitrary extension dissectors, and general field-by-field coverage are not available. Unknown and truncated bytes remain visible as evidence without a guessed protocol interpretation.

For exact fields and limits, see the [protocol reference in the repository](https://github.com/RockxyApp/Tracexy/blob/develop/docs/protocol-support.md) and the [feature coverage matrix](/reference/feature-coverage).
