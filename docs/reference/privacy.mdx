# Local by default

Captured packets and Project History stay on this Mac unless you explicitly export or share them. Live capture uses a signed, narrowly scoped privileged helper; saved capture analysis does not need it. Local History stores bounded terminal summaries rather than raw packet rows.

**Raw packet export preserves bytes.** Privacy controls for investigation and protected-session exports do not sanitize PCAP/PCAPNG. The local Assistant shows the exact bounded selected-session brief before sending it to a configured loopback model endpoint. The optional MCP tool is off until granted and exposes bounded read-only History for one Project, never raw packets or capture control.

[Read the full privacy and security policy](https://github.com/RockxyApp/Tracexy/blob/develop/docs/privacy-and-security.md).
